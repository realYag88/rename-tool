リネームツール
https://caprame.com/tools/rename-tool/

■ 起動
RenameTool.bat をダブルクリックで起動します。
ファイルやフォルダを RenameTool.bat にドロップしても起動できます。
起動時に警告が出る場合は、展開前の zip を右クリック → プロパティ →「許可する」にチェックを入れてから展開してください。

■ 右クリックの「送る」から使う
Install-SendTo.bat を一度実行すると、右クリックの「送る」に「リネームツール」が追加されます。
Windows 11 では右クリック →「その他のオプションを確認」→「送る」です。
RenameTool フォルダを移動した時は、Install-SendTo.bat をもう一度実行してください。

■ 使い方
1. 「フォルダを追加」「ファイルを追加」か、ウィンドウへのドラッグ＆ドロップで対象を入れます。
   フォルダ内のファイルは名前順(frame2 → frame10 の順)で入ります。
   「拡張子」に png,exr のように書くと、フォルダから追加する時にその拡張子だけを拾います。
2. 「リスト全体」か「選択した行だけ」を選びます。
3. タブでモードを選びます。
   [連番] ベース名＋区切り＋番号。開始・桁数・増分を決めます。拡張子はそのまま残ります。
          番号はリストの並び順で振られます。↑↓ボタンで順番を変えられます。
   [置換] 検索した文字を置き換えます。正規表現も使えます($1 などで参照)。
          拡張子は置換の対象外です(チェックで対象にできます)。
4. 新しい名前と状態を確認して「リネーム実行」を押します。
   名前の重複や既存ファイルとの衝突がある時は実行できません。
   直前の1回は「元に戻す」で戻せます。

■ 補足
- 隠しファイル(Thumbs.db など)はフォルダから追加する時に拾いません。
- 途中で失敗した時(ファイルが開かれている時など)は、すべて元の名前に戻します。
- Delete キーでリストから外す、Ctrl+A で全選択。
